For a long time, I didn't want AI to write my code.

My main fear was losing, little by little, my own ability to code, to reason, to think critically.

Then I tried it. It showed what it could do very quickly.

My view now: professionals are the ones who gain the most from it. They know what good code looks like, so they can judge what the AI gives them.

For students, I think it's different. If they use it in the early stages, it can break the learning process. The struggle is how you learn.

On PlugBrain, I used AI to finish the remaining redesign work and the boring refactoring tasks.

But before that, I guarded everything with tests and a solid CI pipeline. If the AI breaks something, the tests say so before anything ships.

We remain the masters. The AI takes the repetitive work, so we can focus on the bigger questions: architecture, user experience, what the app should become.
